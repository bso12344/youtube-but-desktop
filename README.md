# YouTube Desktop

A lightweight, standalone desktop client for YouTube built with **Electron**. Featuring Chromium **Native Picture-in-Picture (PiP)** for seamless video playback in a floating window without interruption.

---

## 🌟 Key Features

* 📌 **Native Picture-in-Picture:** Toggle floating PiP mode instantly via **`Alt + P`** or the options menu.
* 📌 **Always on Top:** Pin the application window above all other apps.
* 🎨 **Minimal Navigation Bar:** Sleek floating controls for Back, Forward, Reload (F5), and Settings at the bottom right.
* ⚙️ **Customizable Settings:**
* Minimize to **System Tray** on close.
* Launch on System Boot.
* Auto-hide navigation bar on hover out.
* And more.


* 🌐 **Multi-language Support:** Automatically matches system language (English, Vietnamese, Spanish, French, German, Japanese, Korean, Chinese).
* 🔒 **Clean & Secure:** Runs in an isolated Electron environment with clean UI and disabled DevTools for production builds.

## 🛠️ Development Setup

### Prerequisites

* [Node.js](https://nodejs.org/?utm_source=gemini) (LTS version recommended)

### Quick Start

1. **Clone the repository:**
```bash
git clone https://github.com/bso12344/youtube-but-desktop.git
cd youtube-but-desktop

```


2. **Install dependencies:**
```bash
npm install

```


3. **Run the app:**
```bash
npm start

```


4. **Build executable (`.exe`):**
```bash
npm run build

```
